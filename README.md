# Консультативные листы UMC

Веб-приложение (PWA): надиктовать данные пациента и сразу получить консультативный лист в PDF.
Бесплатно, работает на компьютере и телефоне. Данные пациентов не покидают устройство.

## Как устроено

- `templates-src/` — исходные шаблоны Word (.docx). **Не публикуются** (внутри печать с подписью).
- `tools/convert.js` — переводит .docx в JSON-шаблоны (`app/templates/`), картинки шапок в `app/img/`.
  Печать из шаблонов не выгружается; пользователь загружает её в настройках на своём устройстве.
- `tools/meta.js` — понятные названия шаблонов и ключевые слова для голосового выбора.
- `app/` — само приложение (статический сайт, без сервера):
  - `js/render.js` — шаблон + данные → PDF (pdfmake, шрифт Arimo = метрики Arial);
  - `js/parse.js` — разбор надиктованного текста правилами (шаблон, ФИО, даты, ИИН, сторона, Shamblin/PUMCH);
  - `js/app.js` — интерфейс, диктовка (Web Speech API), «Поделиться», история;
  - `sw.js`, `manifest.webmanifest` — установка на телефон и работа офлайн.

## Команды

```
npm install                      # один раз
node tools/convert.js            # после изменения/добавления шаблонов в templates-src/
node tools/serve.js              # локальный просмотр: http://localhost:5173
node tools/test-render.js out/   # отрисовать все шаблоны в PDF для проверки
node tools/test-parse.js         # проверить разбор диктовки
```

При обновлении файлов приложения увеличьте `VERSION` в `app/sw.js`, чтобы телефоны получили новую версию.
